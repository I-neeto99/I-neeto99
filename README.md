### Metodologia que eu sigo em cada máquina

</div>

| # | Etapa |
| :--- | :--- |
| 1 | **Reconhecimento** — mapear portas, serviços e versões |
| 2 | **Enumeração** — diretórios, subdomínios, usuários, configuração exposta |
| 3 | **Exploração** — validar o vetor antes de disparar qualquer coisa |
| 4 | **Pós-exploração** — escalar privilégio e entender *por que* funcionou |
| 5 | **Documentação** — anotar o caminho, porque o próximo alvo repete o padrão |
