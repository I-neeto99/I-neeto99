## Sobre

Estudante de **Análise e Desenvolvimento de Sistemas** na FIAP (São Paulo).

Meu objetivo é atuar em **segurança da informação**, e trato backend como base para isso: dá pouco pra defender ou atacar um sistema sem entender como ele é construído. Então divido meu tempo entre duas frentes:

- **Segurança ofensiva** — laboratórios no Hack The Box e TryHackMe, fundamentos de rede, Linux e enumeração.
- **Desenvolvimento backend** — Java e Spring Boot, modelagem de dados e boas práticas de código, aplicados em projetos próprios.

**Buscando:** estágio ou primeira oportunidade em segurança da informação ou desenvolvimento backend.
